# Hospital Management
Full-stack healthcare appointment platform with role-based access (admin, doctor, patient), doctor availability and slot booking, patient history tracking, secure JWT authentication, and responsive Vue + Flask dashboard workflows.

how to run backend on window:
1. go to the backend folder(cd backend)
2. Create virtual environment:
    run these commands
        a. python -m venv venv
        b. venv\Scripts\activate
3. pip install -r requirements.txt

how to run frontend window:
1. got to the frontend folder(cd frontend)
2. npm install
3. npm run dev
